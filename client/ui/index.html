LOCAL ENDPOINT

开放本机控制入口

为当前机器分配一个唯一的公网端口，让另一台 MapLink 设备可以连接本机 SSH。

A、B 两台机器要使用允许范围内的不同端口，例如 A 使用 30022、B 使用 30023。

REMOTE DEVICE

连接另一台设备

请填写服务器地址和 SSH 用户名

连接后直接在下方终端操作，体验与系统终端一致。

手动填写对方系统、SSH 用户名和公网端口后连接终端。

  1. 在对方机器启用 SSH，并在 MapLink 添加本机映射。
  2. 两台机器保存配置并启动各自的 frpc。
  3. 输入对方的公网端口，再检测连接或执行命令。

MapLink 私钥只保存在创建它的设备。远控建立后只把控制端公钥加入受控端授权文件，服务器和另一台设备都无法取得私钥。
