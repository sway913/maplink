# 客户端引导与控制台：规格

- 作者：Codex；依据：已接受的 intent、用户实施方案、README、根与 client/ui/src-tauri AGENTS、2026-09-15 当前 `main` 工作树；决定者：用户；决定日期：2026-09-15；状态：accepted。
- 正常：无已保存配置进入三步引导；一次性配对或手动 Token 后确认首条映射，再保存并启动。已有配置进入概览；停止态可启动，运行态可停止；设置可编辑服务端参数与日志详情。
- 边界：配对成功只表示配置已保存；`client_status.running` 只表示 frpc 进程运行。已有旧 Token 配置仍可用。初始加载时不显示错误状态或引导闪烁。首条 SSH 22 映射仅为示例，必须明确确认。
- 失败与恢复：地址、码或网络错误保留可修正输入；配对码成功后清空。状态读取失败、程序缺失、启动失败、配置未保存和运行中修改分别显示可执行恢复动作；身份字段更改使设备凭据失效并提示重新配对。
- 安全与兼容：不新增 Tauri 命令、API 或 ACL；沿用官方 frpc、现有 Profile 和旧服务器 Token 路径。凭据不进入概览、URL、日志或测试截图。Windows x64 与 macOS Apple Silicon 的页面布局、键盘和安装态结果分别验收。
- 外部边：`/api/client/enroll` 的提供者在独立 `maplink-server`，版本及真实验收为 `unknown`，不得以本仓库 Go 或浏览器夹具宣称通过。
