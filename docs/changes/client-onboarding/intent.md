# 客户端引导与控制台：意图

- 作者：Codex；来源：用户于 2026-09-15 确认的实施方案；决定者：用户；决定日期：2026-09-15；状态：accepted。
- 问题：连接配置页面将服务端、配对、映射和运行详情同时铺开。首次使用者难以判断下一步，已有配置者难以快速管理映射与进程。
- 目标：首次使用显示三步引导；已有配置直接进入状态和映射优先的控制台；进程状态不得冒充服务器在线；旧 Token 路径和远程连接保留。
- 范围：客户端 WebView 页面、相应测试和 CI 门禁；不修改服务端协议、FRP 数据面及权限边界。
- 成功标准：首次用户确认映射后才可启动；配对/启停/错误/身份变化反馈可恢复；单元、集成、浏览器 E2E 与现有跨平台检查成为可追溯门禁。
